# Data Directory

This folder contains dataset descriptions and references used in this study:

1. **Twitter Emotion Dataset**: 40,000 tweets annotated across multiple sentiment classes, mapped down to 4 primary affective states (Happiness, Neutral, Sadness, Worry).
2. **Book Reviews Dataset**: Book metadata and textual reviews paired with Google Books API genre queries. [Couldn't upload due to its large size. Collected from kaggle]
